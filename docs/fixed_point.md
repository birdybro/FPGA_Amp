# Fixed-point contract

The first tube primitive uses quantity-specific formats. These are implementation formats, not physical-model claims.

| Quantity | Unit | Nominal table range | RTL format | Rounding | Out-of-range behavior |
|---|---:|---:|---:|---|---|
| `v_gk` | V | -5 to +1 | signed Q8.24 | input producer contract | clamp and assert `range_clipped` |
| `v_pk` | V | 0 to 400 | signed Q12.20 | input producer contract | clamp and assert `range_clipped` |
| LUT coordinate | index | table extent | unsigned Q16 | add half LSB before reciprocal-scale shift | saturate at final cell |
| `i_p` | A | 0 to about 18 mA | signed Q0.31 | nearest at table generation and each interpolation axis | positive saturated table entry |
| `i_g` | A | about -1 nA to 0.23 mA | signed Q0.31 | same as `i_p` | grid-axis clamp |

`i_p` is bilinearly interpolated from a 128 × 256 table. `i_g` is linearly interpolated from a 128-entry table. Both are generated by `scripts/generate_tube_lut.py` from the Koren equations. Coordinate mapping uses checked-in Q24 reciprocal constants; RTL contains no divider. Mapping uses 64-bit products and interpolation retains the full 49-bit signed product/sum before a rounded 16-bit right shift. Saturation at the physical table boundary replaces wraparound.

The primitive is single-issue, uses one synchronous read port per ROM, and asserts `valid` eight fabric clocks after accepting `ce`. At 96 MHz and a 768 kHz simulation rate, this occupies 8 of the available 125 clocks per tube-current evaluation.

The table itself contributes physical-model approximation error. Q-format, coordinate, and interpolation error are measured together against the analytical model; that number must not be presented as error against a real tube.

## Circuit-state chord candidate

The complete Python fixed candidate uses heterogeneous 32-bit voltage formats:

| Node | Unit | Format | Approximate signed range / LSB |
|---|---:|---:|---:|
| `g1`, `k1`, `g2`, `eq_low`, `k2` | V | Q8.24 | ±128 V / 59.6 nV |
| `p1`, `eq_pre`, `p2`, `out` | V | Q12.20 | ±2048 V / 0.954 µV |
| capacitor history | V | Q12.20 | ±2048 V / 0.954 µV |
| dynamic conductance matrix | S | signed Q0.47, 48 bit | ±1 S / 7.11 fS |
| KCL residual/RHS | A | signed Q4.44, 48 bit | ±8 A / 56.8 fA |
| chord inverse | Ω | signed Q17.15, 32 bit | ±65.536 kΩ / 30.5 µΩ |

Each conductance-voltage product is rounded once into Q4.44 before KCL
accumulation. Tube Q0.31 current is exactly extended by 13 bits. Each chord
correction uses nine 32×48-bit coefficient/residual products, an 84-bit signed
accumulator, one documented add-half/arithmetic shift into the destination node
format, and 32-bit saturation. Capacitor differences are rounded to Q12.20 only
after the corrected node vector is committed.

Exactly three chord corrections execute per sample; the fixed model does not
exit early based on quantized residual. A 2 µA residual diagnostic limit is a
provisional bound derived above the 1.43 µA observed operating-region LUT error,
not a replacement for the float solver's 100 pA criterion. The multitone test
observes 0.342 µA maximum residual with no saturation or LUT range clips.

For 10 mV peak at 50 Hz + 10 mV at 1 kHz + 5 mV at 10 kHz, settled fixed output
is -57.73 dB normalized residual and +0.0100 dB RMS gain from analytical/full-
Newton float. Error decomposition shows the floating LUT circuit itself at
-56.14 dB versus analytical float, while Q-format plus three-pass chord is
-70.92 dB versus the floating LUT circuit. Thus LUT device resolution—not fixed
state arithmetic—is the dominant measured downstream approximation in this test.
