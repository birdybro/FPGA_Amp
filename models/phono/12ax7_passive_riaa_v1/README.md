# 12AX7 passive-RIAA V1 asset

This directory is the stable identity/provenance wrapper for the exact Kennedy
1998 mono circuit. `model.yaml` links the single source of component values, the
ngspice golden reference, Python implementation, and expected nominal results.

The asset category is `reference`. Tube/component tolerance, modern subsonic
filtering, hum reduction, and creative bias/sag controls require distinct mode
metadata and may not alter these expected results in place.
